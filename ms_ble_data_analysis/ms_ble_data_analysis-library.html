ms_ble_data_analysis library

A BLE data analysis library for parsing and handling device data.

This package provides:

  • BLE protocol constants
  • Device key definitions
  • Data models for BLE payloads
  • Platform interface and method channel implementation

Designed for Flutter plugins and cross-platform BLE data parsing.
